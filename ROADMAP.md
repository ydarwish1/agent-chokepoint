# Roadmap

Each step is one small pull request with tests and doc updates. Python 3.10+, no new runtime dependency. Deny by default never weakens: nothing the default branch blocks or sends to ask becomes allowed, the engine stays a pure function, and `policy/policy.example.yaml` and the committed model-run records are never edited.

- [x] 1. Add `chokepoint-policy check POLICY CASES`: CASES is a YAML file of tool calls, each with the verdict and rule id it must get. Run each case through the same loader and engine the doors use, print one line per case, and exit 0 when all match, 1 on any mismatch, 2 when the policy or the cases file does not load. Ship `policy/packs/coding-agent.cases.yaml`, covering every rule in that pack in both directions, and run it in the test suite.
- [ ] 2. Make the decision log tamper-evident: each event written to a log file carries `prev`, the SHA-256 of the previous line (the first event in a file uses a fixed all-zero value). Add `chokepoint-log verify FILE`: exit 0 when the chain holds, 1 naming the first line where it breaks (an edited, deleted, reordered or inserted line), 2 when the file cannot be read. Bump the event schema version and keep older events valid against it.
- [ ] 3. Add two starter policy packs: `policy/packs/research-agent.yaml` (reads and fetches from an allowlist, no writes, no shell) and `policy/packs/support-bot.yaml` (reads tickets and comments, destructive calls blocked, sending email under ask). Each loads with the strict loader, denies by default, and has a cases file that step 1's command checks in the test suite.
- [ ] 4. Add `chokepoint-init --pack NAME` to choose which pack is copied. `coding-agent` stays the default and its output does not change. `--help` lists the packs, and an unknown name exits 2.
