json --- JSON encoder and decoder

Source code: Lib/json/__init__.py

JSON (JavaScript Object Notation), specified by RFC 7159 and by ECMA-404, is a
lightweight data interchange format inspired by JavaScript object literal
syntax.  json exposes an API familiar to users of the standard library marshal
and pickle modules.

  json.dumps(obj)   Serialize obj to a JSON formatted str.
  json.loads(s)     Deserialize s to a Python object.
